# 項目・CSV定義

基準：最終フォルダ一式JSON内の設定・一覧スクリプト。表示名の一部は画面で異なる場合があります。

## 1. 内部項目

|内部名|業務上の意味|使い方|
|---|---|---|
|Title|マスタでは支払先名、支払管理では見出し|支払管理はDateA・ClassAから生成|
|ClassA|支払先|支払管理からマスタへのリンク|
|ClassB|受取人銀行番号|半角数字4桁。先頭0を保持|
|ClassC|受取人支店番号|半角数字3桁。先頭0を保持|
|ClassD|預金種目|1=普通、2=当座、4=貯蓄|
|ClassE|受取人口座番号|半角数字1～7桁。CSVでは7桁ゼロ埋め|
|ClassF|受取人名カナ|許可文字で1～30文字。空白だけは不可|
|ClassH|銀行名|任意。確認用。CSVでは空欄|
|ClassI|支店名|任意。確認用。支払管理では読取専用。CSVでは空欄|
|ClassJ|登録番号|任意。T＋数字13桁。CSV対象外|
|NumA|送金金額|正の整数。CSVでは10桁ゼロ埋め|
|DateA|振込指定日|対象抽出・CSVヘッダの実行日に使用|
|DateB|出力日時|CSV保存後に記録|
|DescriptionA|出力ファイル名|保存ダイアログで指定した実際のファイル名|
|Body|支払管理では摘要／マスタでは備考|CSV対象外|
|Status|状況|支払管理100=未出力、900=出力済。マスタ100=使用中、900=使用停止|
|ResultId|支払レコードID|CSV顧客番号に使用|
|Ver|プリザンターのレコード版|標準システム項目。削除しない|

受取人名と委託者名の許可文字は半角カナｱ～ﾝ、ﾞ、ﾟ、英大文字、数字、`( ) . / -`、半角スペースです。
小書きカナｧ・ｬ等と長音ｰは許可しません。ｱ・ﾔ等と半角ハイフン-を使用します。
入力値を自動で大文字・半角へ変換する処理ではありません。

## 2. 依頼人設定（一覧スクリプトCONFIG）

|キー|意味|設定値|
|---|---|---|
|companyCode|委託者コード|銀行から通知された10桁。初期値1234567890は例示|
|companyName|委託者名|口座名義に合わせた許可半角文字1～40文字。初期値ﾃｽﾄ|
|branch|依頼人支店番号|半角数字3桁。初期値201は例示|
|account|依頼人口座番号|半角数字1～7桁。初期値1234567は例示|

依頼人銀行番号0036、依頼人預金種目1はコードに固定されています。CONFIGにAPIキーは設定しません。
例示値は実利用前に必ず確認・変更してください。別銀行の番号だけを変更して対応できるとは保証しません。

## 3. CSV共通仕様

- 可変長・カンマ区切り・引用符なし。未使用欄も区切りを残します。
- 行順はヘッダ1 → 明細2×件数 → 合計8 → 終端9。各行末はCRLF、最終行にもCRLFを付けます。
- BOMなし。実装のバイト化はASCIIと半角カナの1バイト値（JIS X 0201、Shift-JISの該当範囲と共通）です。
- 銀行公式の表記は「JIS」。ISO-2022-JPへのエスケープ変換はしていません。銀行実取込での確認は未実施です。
- 既定名は `楽天銀行_総合振込_振込日YYYYMMDD_作成YYYYMMDD_HHMMSS.csv`。保存時に変更できます。
- CSVはExcel等で開いて上書きすると先頭0や文字コードが変わる可能性があります。内容確認は元ファイルを保って行います。

## 4. レコードごとの列順

以下は銀行仕様の転載ではなく、同梱スクリプトが実際に出す値の定義です。

### ヘッダ（13列）

|列|出力値|
|---|---|
|1|1|
|2|21|
|3|0|
|4|CONFIG.companyCode|
|5|CONFIG.companyName|
|6|DateAのMMDD|
|7|0036|
|8|空欄|
|9|CONFIG.branch|
|10|空欄|
|11|1|
|12|CONFIG.accountを7桁ゼロ埋め|
|13|空欄|

### 明細（15列、1支払につき1行）

|列|出力値|
|---|---|
|1|2|
|2|ClassB（4桁）|
|3|空欄|
|4|ClassC（3桁）|
|5・6|空欄|
|7|ClassD|
|8|ClassEを7桁ゼロ埋め|
|9|ClassF|
|10|NumAを10桁ゼロ埋め|
|11|1（新規コード）|
|12|ResultId（先頭0なし、最大20桁）|
|13・14・15|空欄|

### 合計・終端

- 合計は4列：`8,明細件数6桁,合計金額12桁,空欄`。
- 終端は2列：`9,空欄`。
- 最後の空欄のため、各レコード末尾のカンマを削らないでください。

形式の根拠：[楽天銀行・依頼ファイルフォーマット](https://www.rakuten-bank.co.jp/business/transfer/upload-format.html)、
[全銀CSV仕様PDF](https://www.rakuten-bank.co.jp/business/howto/pdf/h07_06_10.pdf)（参照日2026-10-15）。銀行受付を保証するものではありません。
