# 利用手順書（支払担当者向け）

## 1. 支払先を登録する

1. 親フォルダから「マスタ支払先」を開き「新規作成」。
2. 支払先名、受取人銀行番号4桁、支店番号3桁、預金種目、口座番号1～7桁、受取人名カナを入力する。
3. 銀行名・支店名・登録番号・備考は必要に応じて入力する。使用する支払先の状況は「使用中」にする。
4. 保存し、表示された内容を確認する。

先頭の0も入力します。受取人名の長音は半角ハイフン`-`にし、小書きカナは大きい文字へ直します。
「使用停止」にしても支払先の選択肢には残るため、選択時に状態を確認してください。

## 2. 支払予定を登録する

1. 「支払管理」を開き「新規作成」。
2. 支払先を選択し、転記された銀行番号・支店番号・口座番号・受取人名を確認する。
3. 送金金額、振込指定日、必要に応じて摘要を入力する。
4. 保存する。新規登録時の状況は「未出力」です。
5. 保存した支払を開き直し、日付・金額・支払先を確認する。

口座情報の訂正はマスタで行い、対象支払で選択し直すなどして転記後の値を確認してください。
コピー済みの値は、マスタ修正だけでは最新になると決めつけないでください。

## 3. CSVを出力する

1. 支払管理の一覧下部のオレンジ色の「全銀CSV出力」を押す。
2. 振込指定日を入力して「CSV出力」を押す。
3. 表示された日付・件数・合計金額を支払予定と照合する。
4. 問題なければ「OK」。保存先とファイル名を指定して保存する。拡張子は.csvにする。
5. 完了通知を確認してOKを押す。一覧が再表示される。
6. 対象が「出力済」になり、出力日時・実際の保存ファイル名が記録されていることを確認する。
7. 保存フォルダでCSVが存在し、空ファイルでないことを確認する。

**一覧で絞り込んだ行だけ、チェックした行だけを出す機能ではありません。指定日の未出力全件が対象です。**
保存直前に対象が変わっていると停止します。内容を確認して「CSV出力」からやり直します。
キャンセル時は出力済に変更しません。保存ダイアログ等による空ファイルが残った場合は内容を確認し、振込に使わないでください。

## 4. 出力後に訂正する

1. 出力済の支払を開き、**状況だけ**を「未出力」に戻して保存する。
2. 開き直して内容を訂正し、保存する。口座情報はマスタと転記結果も確認する。
3. 影響するCSVと、銀行へ送信済みかどうかを確認してから再出力する。

訂正対象だけを未出力に戻して出すと、前のCSVの一部と重複します。
銀行へ送信済みの場合は、銀行側の依頼状況・取消や差替えの可否を確認してから進めてください。
状況を戻しただけでは、出力日時とファイル名は消えません。次の出力成功時に更新されます。

## 5. 銀行への取込

このツールが行うのはCSV作成と出力記録までです。銀行側でのファイル指定・受付内容確認・承認は別の操作です。
選ぶ形式は「全銀フォーマット（CSV）」に対応するものです。固定長や楽天銀行独自CSVと取り違えないでください。
銀行画面の手順や現在の受付条件は[楽天銀行公式案内](https://www.rakuten-bank.co.jp/business/transfer/upload-format.html)を確認してください。
銀行画面の実操作・受付・振込完了は今回検証していないため、本書では特定のクリック順を断定しません。
