# プリザンターから楽天銀行向け全銀CSVを出力するサンプル

支払先と支払予定をプリザンターで管理し、指定日の「未出力」をまとめてCSVに保存します。
対象は**楽天銀行・法人総合振込の全銀フォーマット（CSV）**です。120バイト固定長形式と楽天銀行独自CSVは対象外です。

版：v0.2.0 Excel同梱・公開準備版／作成日：2026-10-16

## Excelから出力する場合

[Excel設定・操作手順書](docs/09_Excel設定・操作手順書.md)から始めてください。
ブラウザとExcelは同じ支払データを扱う別の出力方法です。同じ支払を同時に出力しないでください。

## 配布物

- `site-package/全銀CSV出力_v0.1.0.json`：親フォルダ・支払管理・支払先マスタの一式。新規インポート用。実データなし。
- `src/一覧CSV出力.js`：JSONから抽出した一覧画面用スクリプト。
- `src/server/01.js`～`03.js`：JSONから抽出したサーバースクリプト。
- `tests/`：配布JSON・ソースの整合性と、模擬ブラウザ/APIを検証するNode.jsスクリプト。
- [Excelツール](excel/楽天銀行_全銀CSV出力_配布用_v1.1.xlsm)：Windowsデスクトップ版Excel用。初期設定・支払データ・CSV確認・ログは空です。
- `src/excel/`：同梱Excelから抽出したVBA、カレンダーフォームと関連ファイル（日本語コードはCP932）。ソース編集だけではブックに反映されません。
- `SHA256SUMS.txt`：同梱ファイルの確認用ハッシュ。

通常の導入ではJSONを取り込みます。JSを追加で登録する必要はありません。Excelを利用する場合は、続けてExcelの接続・依頼人口座を設定します。
JSファイルだけを書き換えてもJSONへ自動反映されません。

## 利用条件と現在の確認範囲

- 元JSONの出力元はPleasanter 1.5.2.0。別バージョンの互換性は未確認です。
- ブラウザ出力は保存先指定機能に対応したPC版Edge／Chromeとセキュアな接続環境を前提とします。環境ごとの確認が必要です。
- 日付、金額、件数を確認してから保存し、その後プリザンターへ出力情報を記録します。
- **「出力済」はCSV保存・出力記録の状態です。銀行への送信・承認・振込完了を意味しません。**
- 最終JSONは2026-10-15に利用者が指定したフォルダ一式です。公開用コピーの新規インポートと銀行の実取込は未確認です。
- 同時実行を完全に防ぐ仕組みはありません。同じ支払管理を複数人・複数タブ・Excelから同時出力しない運用にしてください。
- ライセンスは未選定です。再利用条件を定める場合は公開前に決めてください。

最初は検証用サイト・架空データで試してください。銀行側での操作は別途必要です。
銀行形式の区別と仕様は[楽天銀行公式案内](https://www.rakuten-bank.co.jp/business/transfer/upload-format.html)を参照してください。

## ローカル確認

Node.jsが使える環境で、このフォルダをカレントフォルダにして実行します。

```powershell
node tests/verify-package.cjs
node tests/browser-flow.cjs
```

追加パッケージのインストールは不要です。実サイトや銀行への通信は行いません。
